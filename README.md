# Mailbox Speed Dial

Mailbox Speed Dial adds an account-wide recipient list to the WoW: Forever Send Mail tab.

The included Warcraft-style dial and envelope icon is used by the in-game tab and addon managers.

## Features

- Save recipients and click a name to fill the game's recipient field.
- Add recipients at the top of the list, move saved names to the top, or remove them.
- Scroll through a recipient list of any length.
- Supports Unicode text in recipient names and removes ASCII digits (`0`–`9`) from new input.

## Install

Copy the `MailboxSpeedDial` folder into `World of Warcraft\_forever_\Interface\AddOns\`, then enable the addon and reload the UI.

Open a mailbox, choose **Send Mail**, and select the mail icon beside the window to open the list.
